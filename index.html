第一部分

七個風格特點

先學會「看」。這七點是之後每一個調整步驟的依據。

影調

低長調

整體偏暗，比高調更穩重、帶點神秘感。高長調適合輕鬆明快的氛圍，低長調剛好相反，依你想傳達的情緒來選。

00:58
對比

明暗對比無處不在

明亮的臉配深色頭髮或深色衣服，把人物推出來。大部分作品都有加對比度，可以從直方圖判斷（見下方圖）。

01:22
主體

主角明確，膚色亮而淡

臉部非常明亮，膚色亮度 L ≥ 80，飽和度很低。後面會教你怎麼用 Lab 數值邊調邊檢查。

02:07
配色

互補色：青橙對比

橙配青、紅配綠。可以是高飽和橙配低飽和青，也可以反過來。很多風格的差異，其實只是橙與青的明度、飽和度組合不同。

02:29
色溫

暖調居多

雖然是冷暖對比，但畫面裡暖色多於冷色。看不出來時看直方圖：亮部與中間調有較多紅色和黃色，就是暖調。

03:04
服裝

衣著多為中性色

黑、白、灰、棕、米色。中性色是調和色，能平衡畫面裡的多個顏色，讓青橙對比不被干擾。

03:31
質感

膠片感：黑色缺失

所有作品都看不到純黑，有些連純白也沒有。做法很簡單：把曲線的端點往內收，讓尾部上翹。

03:47
第二部分

實作：八個步驟調出來

素材的問題：主角的臉完全在陰影裡，最亮的地方反而是袖子；直方圖亮部不多、黑色溢出。原則是主角在哪，光就打哪。建議開啟原圖／效果圖對比模式，方便看前後差異。

  1. 白平衡與整體曝光

    04:36

    用白平衡吸管點畫面中的白色，讓軟件自動校正。原圖偏暖，校正後恢復正常，而且陰影帶點青色，這正是後面要的效果。接著重塑光線：

    基本 Basic
    陰影 Shadows＋ 提亮，救回溢出的黑
    高光 Highlights−100
    黑色 Blacks＋ 顯出暗部細節
    白色 Whites＋ 少量
    對比度 Contrast＋ 壓平中間波峰

  2. 用 Lab 精準提亮膚色

    05:37

    人眼會先找畫面最亮的地方，所以要照亮主體。滑鼠移過畫面時，直方圖下方會顯示 L a b 數值；L 是亮度，0–100。沒看到的話，在直方圖上按右鍵，勾選顯示 Lab 色彩值。按 S 使用顏色取樣器，可以在畫面上固定取樣點。

    素材臉部 L = 50，太暗；SamAlive 的膚色通常在 80 以上。用筆刷（調小尺寸、降低流量）塗出陰影中的臉和手臂：

    筆刷 Brush · 臉部與手臂
    曝光 / 陰影 / 白色 / 高光＋
    紋理 Texture−
    清晰度 Clarity−13
    結果L 50 → 85

    清晰度降太多會變糊，柔膚到 −13 就夠。

  3. 用 a、b 值檢查膚色色相

    07:34

    素材膚色 a = 15、b = 9：都是正數，但 a 比 b 大很多，代表偏紅。增加色溫，直到 a = b = 9，膚色正確且飽和度低，這是亮白膚色的參考值。完整規則與檢查器在第三部分。

  4. 頭髮層次，與背景分開

    09:42

    頭髮、植物、窗內陰影全混在一起。SamAlive 的人物頭髮多為深色，但會留一點高光，避免變成一團不透氣的黑。把筆刷調小，沿用剛才的曝光設定，描出頭髮的高光，人物就和其他暗部分開了。

  5. 曲線做膠片感

    10:21

    在曲線裡把黑點往上拉，黑色缺失；也可以同時把白點往下壓。亮度被壓縮在一段範圍內，畫面沒有純黑純白，這就是常說的迷幻黑、迷幻白。到這裡，低長調、強對比、黑色缺失三點都到位了。

  6. 混色器：衣服改中性色，建立青橙

    10:49

    衣服是紫紅色，會破壞青橙調。在混色器把它的色相推向藍，再降飽和度；口紅太鮮豔，就降紅色飽和度。衣服上去不掉的色塊，用筆刷塗出來，飽和度 −100。失去明確色相後，衣服就成了中性色。

    膚色與桌子已經在橙色範圍，白平衡後陰影也已經偏青，只要把藍色色相往青色稍微推，橙青對比就成形了。

  7. 顏色分級統一色調

    11:51
    顏色分級 Color Grading
    高光 Highlights橙黃
    陰影 Shadows青 · 只加一點
    中間調 Midtones反向平衡

    中間調很多人不知道怎麼調。人物通常落在中間調：高光加了暖、陰影加了冷之後，如果人物看起來太冷，中間調就加暖；太暖就加冷。這張素材加的是暖色。可以在第四部分的灰階條上試。

  8. 空間感、銳化、暈影與顆粒

    12:39

    有一塊暗部缺少層次，用漸層濾鏡順著光的方向加曝光，再降低去除薄霧，讓那裡變朦朧。背景更虛，前景更清楚，空間感就出來了。

第三部分 · Lab 精準調色法

膚色檢查器

不管黃皮膚、白皮膚、黑皮膚，正確膚色都落在同一條色相線上，差別只在亮度與飽和度。判斷只要兩個條件：a、b 都是正數，而且a ≈ b。

試試這些數值

a 軸：負為綠、正為紅。b 軸：負為藍、正為黃。虛線是 a = b 的標準膚色線，離原點越遠飽和度越高。

情況a、b 數值亮度 L意義
白皮膚a ≈ b ≈ 1080–90飽和度低、亮度高
黑皮膚a ≈ b ≈ 20–30≈ 50飽和度較高、亮度較低
偏紅a > b—增加色溫（往黃）把 b 拉上來
偏黃b > a—降低色溫，或往洋紅調色調
冷色a、b 皆為負—用來檢查青色、藍色、天空、海水
第四部分 · 顏色分級

在灰階上看懂三個色輪

影片用一條灰階示範顏色分級：高光加橙、陰影加青之後，中間調負責平衡。拖動滑桿，看每一段亮度怎麼被染色。

總結

SamAlive 風格檢查清單

低長調、強對比

整體偏暗，對比度拉高，直方圖中間波峰要平。

主角明確

膚色 L ≥ 80，a ≈ b 且數值低，飽和度淡。

互補配色

青橙對比；衣著改中性色，唇色收斂。

膠片質感

曲線黑點上翹做黑色缺失，再加顆粒與暈影。
